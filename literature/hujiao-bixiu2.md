# 沪教版必修 2《信息系统与社会》

来源：本地教材 `高中-沪教必修二.pdf`（信息技术，必修 2，信息系统与社会；上海科技教育出版社，写给同学的话与目录可核对）。下面只记结构和对任务设计有用的活动，不复述课文。

本学期课堂不做编程。第二单元学习目标里出现过「借助软件工具与开源模块做简单的网络应用软件」，评价条目里也有开发一个手机点餐应用。这些不进入网页。

## 第一块网页对准项目二

教材把信息系统写成由人员、硬件、软件、数据和网络构成，用来完成信息的输入、存储、处理、输出和控制。项目二的活动是递进的：

- 活动 2.1：选定一个信息系统（课文举例是网络购票平台），写出业务功能，并描述每个业务里信息如何被输入、存储、处理、输出。
- 活动 2.2：分析「新卡充值」这一业务涉及哪些组成要素，每类举本系统的例子，并说明它们如何配合。表里已有人员、硬件、数据的提示行。
- 活动 2.3：对 2.1 里自己选的那个系统做同样的要素分析，再对照公交 IC 卡，归纳组成要素。支架应在这一步撤掉。
- 活动 2.4、2.5：从使用者和管理者两个角度写优势，并写出局限。适合作为同一单元的后续任务，检查方式比 2.2 松。

## 事件不再来自编程

学生改的是表格和协同关系，不是程序。一次「没通过」指同一格检查未过，例如把余额填进硬件、五类里缺软件或网络、协同关系里看不出数据传到哪里、活动 2.3 仍在抄公交充值的例子。

项目六的 IP 规划（活动 6.1：按数字家庭的功能为设备规划地址并作图）是后一单元里更容易自动检查的任务。真机上改路由器不放进网页。
