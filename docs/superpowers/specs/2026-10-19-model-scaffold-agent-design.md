# 模型支架智能体

高中信息科技课里，学生求助后，支架智能体按已经选定的支架类型和这句提问给出支架。本规格只把支架智能体换成 DeepSeek。会话怎样接收支架智能体、空支架或调用失败时怎样留下已有支架，仍按支架闭环规格执行。

决策智能体、任务生成方和目标提炼方不在这里。测试不访问网络。

## 组件

新增模型支架智能体。会话仍接收一个支架智能体。已有的脚本支架智能体和已有测试保持不动。

**模型支架智能体**实现现有的 `produce(scaffold_type, question, questions, answers)`。它组两条消息，调用一次完成函数，把正文解析成现有的支架草稿并交回。草稿里的文字和 HTML 来自正文，素材列表为空。它不保存记录，不读取密钥，也不读取行为记录。

完成函数是任务生成里已有的 DeepSeek 完成函数。测试换上返回事先写好正文的函数。本规格不修改这个完成函数。

构造会话时，把模型支架智能体当作原来的支架智能体传入。会话本身不修改。素材仍由会话里现有的 HTML 解析从草稿的 HTML 抽出。

## 提示词

系统消息是固定说明。用户消息只写这次求助要用的材料。

系统消息要求模型只回一个 JSON 对象，不要代码块，不要其他文字。顶层只有「文字」和「HTML」。两个值都是字符串，可以是空字符串。HTML 里只放四类素材，写成 `<asset kind="…" name="…">…</asset>`。`kind` 是图片素材、思维导图、结构图、微格动画之一，`name` 是文件名。支架的文字和 HTML 不要写出参考答案，也不要写出学情。

用户消息按题目顺序写。每题包含题型、题干、选项或作答要求、参考答案、解析、当前作答、修改痕迹。选择题的题型写成「单选」或「多选」，并列出全部选项。判断题的题型写成「判断」，选项是正确和错误。综合题的题型写成「综合」，并写上作答要求。开放题没有参考答案或解析时，那一项留空。选择题和判断题的当前作答按记录里的先后写出当前选择，综合题写当前文字。没有作答时这一项为空。修改痕迹按先后列出。没有修改痕迹时这一项为空。消息末尾写这次已经选定的支架类型，以及学生这次提问的原话。

用户消息用拼接组成，不对这段正文做字符串格式化。不放停留时间、求助记录、学情、其他任务、知识库或教学目标。

## 正文

正文去掉前后空白后，必须直接是一个 JSON 对象。完成函数交回的不是字符串时，也算解析失败。

顶层只有「文字」和「HTML」，两个值都是字符串：

```json
{
  "文字": "先看人员和硬件是否都写到了。",
  "HTML": "<asset kind=\"思维导图\" name=\"组成.svg\">人员—硬件</asset>"
}
```

文字和 HTML 按模型原文放进草稿，包括只有空白的文字。素材列表为空。两个值都是空字符串时，仍然交回这份草稿。

不检查文字或 HTML 里有没有参考答案原文。不检查传入的类型是不是六类之一，类型原样写进用户消息。

## 失败

解析失败时，模型支架智能体抛出它自己的 `Rejected`。这个异常不属于任务发布。完成函数抛出的异常原样传出。模型支架智能体不接住这些异常。完成函数只调用一次，不重试。

下面这些是解析失败：

- 正文去掉前后空白后不能直接解析成上面的 JSON。包在代码块里也算失败。
- 顶层键多了或少了。
- 「文字」或「HTML」的值不是字符串。

下面这些不是调用失败。完成函数已经被调用过一次，草稿照常交回：

- 「文字」或「HTML」是空字符串。
- 文字只有空白。
- HTML 里没有可抽出的四类素材。

会话不修改，因此现场按现有规则保留：

- 求助时，`Rejected` 或完成函数抛出的异常被会话接住。已有支架和预设提问保留。
- 草稿里的文字去掉前后空白后没有字，并且 HTML 抽不出四类素材时，会话把它当成空支架，留下上一次的支架。
- 不属于四类、文件名不安全、正文只有空白的素材，仍由现有 HTML 解析丢掉。其余素材按现有规则显示和导出。
- 打开会话时不调用支架智能体。

## 测试

已有的脚本支架智能体和已有测试保持通过。新增测试不访问网络。

- 系统消息写明 JSON 只有「文字」和「HTML」，两个值都是字符串，HTML 只用四类素材的 asset 标签，并且不要写出参考答案，不要写出学情。
- 用户消息含题型、题干、选项或作答要求、参考答案、解析、当前作答、修改痕迹、这次的支架类型和这次提问的原话。记录里的停留秒数和历次求助原话不出现在用户消息里。提问原话里的花括号原样保留。
- 一段含文字和 HTML 的正文交回后，草稿里的文字和 HTML 是模型原文，素材列表为空。完成函数只被调用一次。
- 两个值都是空字符串时，交回空草稿，不抛出异常。
- 代码块、键不对、值不是字符串，或完成函数抛出异常时，按上面的失败规则结束。完成函数只被调用一次。
- 把模型支架智能体传进现有会话后，合法正文让页面显示文字和从 HTML 抽出的素材。正文为空，或调用失败时，已有支架保留。

会话、HTML 解析、决策智能体、任务生成、目标提炼和已有的 DeepSeek 完成函数不被修改。
