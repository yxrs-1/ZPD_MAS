# 按目标生成

高中信息科技课里，教师在目标页上按已经保存的教学目标生成一份未发布任务。本规格只描述目标页上的「按目标生成」。

知识库的上传不在这里。教材和课标的预置内容不在这里。文字生成页、课时生成、学段生成、学生页和任务页的原有规则不改。测试不监听端口，不打开浏览器，也不访问网络。

## 服务

任务生成记录增加一个入口。它接收当前查询已经保存的目标，以及这份查询对应的来源。课时查询用来源里的版本、册次、课时。学段查询用来源里的学段。来源按目标页现有的任务链接来比对。来源仍记在这次进程的任务生成记录里，进程结束后不保留。

这个入口不读知识库，不提炼，也不走原来的课时生成和学段生成。按文字生成仍不写来源。

已保存目标按保存顺序写成文字。每条两行，先是 `维度：` 紧接维度，再是 `表述：` 紧接表述，用的是保存下来的原文。各行用换行连接，中间不插空行，末尾不另加空行。文字最后单独一行是 `没有指定题型和数量。`

没有文字生成方，或目标一条都没有时，不调用模型。有目标时最多调用一次，用的是课堂里已有的文字生成方。

交回仍用现有核对：读法、目标、题目都要合格。交回的目标核对之后丢掉，不写入目标库，也不要求和已保存的目标逐条相同。已保存的目标保持原样。读法里的整数仍按指定数量核对，「未指定」仍接受交回的题数。四类合计至少一道。题目按单选、多选、判断、综合排列，同一类保持交回的先后。

核对通过后创建一份未发布任务，并写上这次的来源。每提交一次「按目标生成」，另创建一份。它出现在教师任务列表里，也出现在这次查询的任务链接里。

正式运行使用课堂里已有的文字生成方。测试注入事先写好的交回。

## 页面和路径

「按目标生成」是目标页上的一个提交按钮，按钮上的字就是这四个字。提交字段的名字是 `action`，值也是这四个字。当前查询已经有保存的目标时才出现，放在这些目标后面、任务链接前面。整页只有一个，不放进某一条目标的修改或删除表单。它单独提交，带上和修改、删除相同的查询字段，提交地址仍是目标页。课堂里带 `/teacher`，单独调用教师页时不带前缀。

还没有查询、查询后还没有目标、最后一条目标被删掉时，不显示这个按钮。查看、提炼、修改、删除之后，只要这份查询仍有目标，按钮就在。检索没有资料、但目标还在时，按钮也在。

查询表单旁的「生成」仍是链接，仍打开文字生成页，不提交目标页。教师列表和课堂入口不增加「按目标生成」。

点「按目标生成」并且成功时，这次响应就是现有任务页，状态是 200，标为未发布。回到这次查询再点一次，另创建一份，来源相同。页面上出现的原文、表述、题目和标识都按文字写进页面。HTML 用拼接，不用 `str.format`。

学生页不增加这个按钮。末尾多一个斜杠或带查询字符串，仍按目标页现有规则打开。

## 失败

「按目标生成」失败时仍停在目标页，状态是 200。这次查询的原文、已保存目标和已有任务链接都还在，并显示「生成失败，没有创建任务」。不创建任务。知识库、目标库和已有任务都保持原样。

下面这些情况都是这一句，并且不调用模型：

- 当前查询一条已保存的目标都没有。
- 教师页没有任务生成记录，或者记录里没有文字生成方。

模型调用失败，或交回无法按现有文字核对接受，也是这一句。这里包括读法缺类或数量说不清、出现四种以外的题型、交回的目标为空或维度不合格或表述为空白、题目不符合规则、指定数量对不上、指定为 0 的那一类仍有题、四类合起来没有题。这些时候模型最多被调用一次。

查询字段没填完整时，仍显示「先填完整再查询」，不检索，不调用模型，页面上没有原文、目标和任务链接。不认识的动作仍只显示查询，不另报失败。「按目标生成」是目标页认识的动作。

检索没有资料时，失败句代替「没有检索到资料」。已有目标和来源对得上的任务链接仍显示，不显示半份原文。

学生页仍显示「任务不存在」，状态是 404。

## 测试

测试调用教师页和课堂的处理函数，注入事先写好的文字交回。测试不调用监听，不打开浏览器，也不访问网络。课时生成、学段生成和按文字生成的原有规则仍要成立。

下面这些必须成立：

- 当前查询已经有目标时，目标后面、任务链接前面有一个「按目标生成」。它单独提交，动作为这四个字，并带上和修改、删除相同的查询字段。还没有查询、还没有目标，或最后一条被删掉时，没有这个按钮。查看、提炼、修改、删除之后，只要目标还在，按钮就在。检索没有资料但目标还在时，按钮也在。
- 查询表单旁的「生成」仍指向文字生成页。教师列表和课堂入口没有「按目标生成」。课堂里按钮的提交地址以 `/teacher` 开头，单独调用教师页时不带前缀。
- 课时查询提交「按目标生成」后，创建一份未发布任务。响应是这份任务的任务页，状态是 200。题目按单选、多选、判断、综合排列。文字生成方被调用一次，收到的文字就是服务一节规定的那几行。出题方不被调用。目标库里的目标不变。任务带这份课时来源，任务列表里有它。再打开这次查询，任务链接里有它。回到这次查询再点一次，另创建一份，来源相同。
- 学段查询写入学段来源。同一学段的课时来源不对上这次查询的任务链接。按文字生成仍不写来源，它创建的任务不出现在这次查询的任务链接里。
- 当前查询没有目标、没有任务生成记录，或记录里没有文字生成方时，显示「生成失败，没有创建任务」，状态是 200，不调用模型，不创建任务。原文、已有目标和已有任务链接保持原样。
- 模型调用失败，或交回无法接受，也是这一句。模型最多调用一次。不创建任务。知识库、目标库和已有任务保持原样。检索没有资料时，页面显示的是这句失败，已有目标和来源对得上的任务链接仍在。
- 查询字段没填完整时，显示「先填完整再查询」，不调用模型。不认识的动作仍只显示查询。
- 表述里的 `<` 在目标页按文字显示。学生页没有这个按钮，学生地址仍显示「任务不存在」，状态是 404。
