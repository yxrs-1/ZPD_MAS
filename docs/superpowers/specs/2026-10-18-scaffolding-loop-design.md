# 支架闭环

高中信息科技课里，学生做任务时向系统求助，系统按学情选定支架类型，并针对学生的这句提问给出支架。本规格只描述这条闭环。任务生成、知识库和教学目标不在这里。

## 范围

学生做的是教师写好的样例任务。任务可以是实践作品，学生在页面里完成并反复修改；也可以是选择题或判断题。具体类型和数量由任务模块确定。闭环不绑定某一种题型。

闭环每次看整份任务的全部作答，不只看学生正在做的那一道。

对照试验不在系统功能里。系统只负责在学生做任务时提供支架。

## 智能体

### 决策智能体

决策智能体读取任务陈述、整份作答和行为记录。它自己判断学情。学情说明只留在它内部。

它做两件事：

- 生成预设提问，显示在页面上。
- 学生求助后，从六类支架中选一类：反馈、提示、指导、解释、示范、提问。这六类来自 van de Pol、Volman 与 Beishuizen（2010）。

学生不求助，它不选定类型，页面上也不出现支架。

### 支架智能体

支架智能体收到两样东西：决策智能体选定的类型，以及学生这次提问的原话。提问可以是一条预设提问，也可以是学生自己写的。

它再读取任务陈述和整份作答，针对这句提问给出支架。它不读取行为记录，也不接收学情说明。

形式由它决定：文字、HTML 支架，或两种一起。HTML 支架里只放四类内容：图片素材、思维导图、结构图、微格动画。网页上具体画什么，由它按任务内容和这句提问决定。

## 记录

任务模块提供任务陈述，包括题目、选项和作品要求。闭环只读，不修改题目。

一份任务记录有三部分：

- **任务陈述。** 题目、选项、作品要求。
- **作答。** 整份任务的当前内容，以及学生改过的痕迹。学生还没作答时，这一部分可以为空。
- **行为。** 停留时间，以及每次求助。每次求助记下原话，并标明它来自预设提问还是学生自己写的。

决策智能体写出预设提问；学生求助后，再写出六类中的一类。支架智能体写出文字、HTML 支架中的内容，或两种。导出时按件保存实际产出的图片素材、思维导图、结构图和微格动画，不保存整个 HTML 页面。

## 一次求助

页面保存作答、修改、停留时间和求助。学生还没求助时，页面只显示预设提问。

学生改完作答后，决策智能体重新读取整份记录，更新预设提问。

学生点一条预设提问，或自己写一句，都算一次求助。决策智能体据此再判断一次，只输出六类中的一类。支架智能体用这个类型和提问原话生成支架。

## 失败

学生没写提问，也没点预设提问，这次不调用两个智能体。

决策智能体给出的类型不在六类之中，或者这次调用失败，页面不显示支架。已有的预设提问保留，学生可以再求助。

支架智能体没有写出文字，也没有写出四类内容中的任何一件，页面不显示支架。HTML 里不属于这四类的部分丢掉，不展示，也不导出。

作答为空时，学生仍然可以求助。决策智能体照常选类型。支架智能体根据任务陈述和这句提问给出支架。

## 测试

用教师写好的一份样例任务测试。作答可以为空，也可以同时包含选择、判断和一份改过的作品。下面这些必须成立：

- 学生还没求助时，页面上有预设提问，没有支架。
- 点预设提问，或自己写一句，都会把这句原话和六类中的一类交给支架智能体。行为记录和学情说明不在其中。
- 支架针对这句提问。形式是文字、HTML 支架，或两种。HTML 里只有图片素材、思维导图、结构图、微格动画。
- 导出得到的是实际产出的那些内容，不是整个 HTML 页面。
- 没写提问、类型不在六类之中、调用失败，或支架为空时，页面上不出现支架。已有的预设提问还在。

任务生成、知识库和教学目标不在这次测试里。
