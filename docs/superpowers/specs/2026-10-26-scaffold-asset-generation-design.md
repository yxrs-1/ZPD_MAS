# 支架素材改为示例加代码出图

学生提问后，支架智能体仍先给一段文字。文字以外的四类素材不再由模型直接写 HTML。任务生成之后先准备一份示例，示例里保存的是可渲染的源码。学生真正提问时，模型只改这份源码，再由本地代码画出图。学生看到的是图，不是一个 HTML 文件名。

这一规格只定生成和显示。不改支架类型的六类选择，不改提问、保存、提交和对话栏的位置。

## 现在的问题

模型被要求只回「文字」和「HTML」。HTML 里用 `<asset kind name>` 包住素材正文。学生页只把 png、jpg、jpeg、gif、webp、svg 画成图片。其他文件显示类型、文件名和「保存」。

因此模型若交出 `带宽与延迟关系导图.html`，对话里就出现「思维导图」和这个文件名，旁边是「保存」，图本身不出现。素材正文即使是一段 HTML，也不会被嵌进页面。

## 两段生成

**示例。** 题目确定之后，为这个任务准备一份示例，不针对某一个学生。示例有三件：思维导图、结构图、微格动画。每件保存两样东西：模型写的源码，以及源码画出来的 SVG。文字支架不放进示例，仍在学生提问时现写，因为文字必须对着那一句提问。

示例不挡在「确认」按钮上。确认仍先把任务建好。示例放到已有的后台任务里做。学生若在示例完成之前提问，只给文字，不临时拼一个 HTML 文件。

**当场。** 学生提问后，决策仍先选定支架类型。提示和指导用思维导图，解释用结构图，示范用微格动画。反馈和提问只有文字。需要图时，把对应那一件示例的源码、这句提问和当前作答交给模型。模型交回同一格式的源码，外加这次的支架文字。本地渲染器把源码画成新的 SVG。源码通不过检查时，文字用这次新写的，图沿用示例，不把失败的源码显示给学生。

不把课堂内容送到外部画图网站。

## 源码和渲染器

模型不再写 HTML，也不写文件名。它只写下面三种源码。渲染器是仓库里的代码，输入源码，输出 SVG。文件名由程序生成，扩展名是 svg。学生页因此会把它当成图片显示。

| 素材 | 源码 | 参考 |
| --- | --- | --- |
| 思维导图 | 缩进大纲。第一行是根，子节点多缩进一层 | [markmap](https://github.com/markmap/markmap/) 用纯文本生成思维导图。这里只借用大纲，不在接口容器里跑浏览器 |
| 结构图 | 若干节点和带标签的箭头 | [Mermaid](https://github.com/mermaid-js/mermaid) 的流程图，以及 [D2](https://github.com/d2lang/d2) 的「文本进、SVG 出」。渲染用本地代码，不调用 [Kroki](https://kroki.io/) |
| 微格动画 | 有顺序的若干帧。每一帧复用结构图的节点和箭头，并标明这一帧高亮哪一个节点 | [Manim](https://github.com/ManimCommunity/manim/) 说明动画应由场景代码产生。它依赖 TeX 和视频编码，不放进提问路径。渲染器按帧画出同一张结构图，并让高亮在帧之间移动 |

图片素材不另开一种源码。没有真实照片时，不生成图片素材，也不用 HTML 冒充图片。

渲染器拒绝空大纲、没有节点的结构图、没有步骤的动画，以及源码里的脚本和 HTML 标签。拒绝后按上面的当场规则退回示例图。

## 学生看到什么

对话里的素材仍是现在的文件。扩展名是 svg 的，继续用图片显示。微格动画的 SVG 自身带一段短动画，不另嵌 HTML 页面。已经存在的 HTML 素材保持原样，仍是类型、文件名和「保存」，不补画。

## 不做的事

不让模型继续写 `<asset>` HTML。不在提问时调用 Manim，也不生成 mp4。不把思维导图、结构图和动画各按六类支架类型都预生成一遍。不改决策智能体选择支架类型的方式。
