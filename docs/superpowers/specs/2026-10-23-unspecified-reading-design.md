# 未指定读法

教师在需求或文字里可以不写题目类型和数量。模型把「读法」交回为「未指定」时，核对接受这份交回并创建未发布任务。这不算失败。

文字生成和确认共用这一套核对。提示词、失败句和页面不改。测试不调用监听，不打开浏览器，也不访问网络。

## 核对

交回仍是只有「读法」「目标」「题目」的对象。「读法」去掉两端空白后恰好是「未指定」时，单选、多选、判断、综合都由模型决定，题数照交回保留。目标和题目仍按文字生成已有规则核对。四类合起来至少一道。

「读法」仍是单选、多选、判断、综合四个键时，规则不变。写明的数量必须一致，没写的类照交回保留。

「读法」是其他字符串、缺类、多类、某一类对不上写明的数量，或四类一道题都没有，仍然整份拒绝。页面仍显示「生成失败，没有创建任务」，不创建任务。

## 测试

测试把 JSON 字符串交给现有的题目核对。

- 「读法」去掉两端空白后是「未指定」，并带有一道合格综合题时，核对得到这道题。
- 「读法」是其他字符串，或四种题都是空数组时，仍然拒绝。
