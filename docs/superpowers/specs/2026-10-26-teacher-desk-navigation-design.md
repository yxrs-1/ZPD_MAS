# 教师页的宽度、返回和账号面板

教师登录后的页面仍是现在这一套：左侧导航，右侧正文，纸色和粉笔黄不变，题目仍是单行输入。这一规格只改三件事。宽于 800px 时，导航变窄，正文占满剩下的宽度。从列表点进下一层时，标题上方有「返回」。左下角账号面板在点到外面、按 Escape 或换页时收起。

不改登录页，不改学生页，不改接口，不改任务、班级、资料和密码的原有动作。不把题目改成多行，不加确认框，不加纸面卡片，也不改字重和配色。不把账号面板的展开写进地址。

## 左右宽度

现在左侧导航是固定 212px，右侧正文最大 840px，并且靠左。窗口再宽，右边就空出一块墙。

窗口宽于 800px 时：

- 导航宽度是 `clamp(160px, 15vw, 200px)`。四项文字、圆环标志和底部账号仍放得下。
- 正文取消 840px 上限，占满导航右侧的整栏。现有内边距 36px 40px 108px 保留。
- 底部操作条仍贴着正文这一栏的底边，不伸进导航。

窗口在 800px 及以下时，导航仍排在正文上面，宽度仍随窗口走，不使用上面的 clamp。

## 返回

四个一级页面没有「返回」：任务列表 `/teacher`、班级列表 `/teacher/classes`、资料库 `/teacher/documents`、账号管理 `/teacher/accounts`。左侧导航就是这些页面之间的通路。

从一级页面再点进去的页面，在标题上方放一个链接，可见文字是「返回」。它是 `<a>`，地址写在 `href` 上，可以中键打开。点它进入下表里的固定上一层，不调用浏览器的后退。这样从目标确认进入任务之后，返回回到任务列表，而不是回到目标。

| 当前页 | 返回到 |
| --- | --- |
| 新建任务 `/teacher/tasks/new` | `/teacher` |
| 目标 `/teacher/objectives` | `/teacher/tasks/new` |
| 任务详情 `/teacher/tasks/{task_id}` | `/teacher` |
| 班级详情 `/teacher/classes/{class_id}` | `/teacher/classes` |
| 学生详情 `/teacher/classes/{class_id}/students/{account}` | `/teacher/classes/{class_id}` |

「返回」不放进左侧导航，也不替换标题、新建、导入、保存、发布或删除。任务详情里原有的删除、放弃草稿和布置仍留在原处。

## 账号面板

左下角仍是教师账号。点它展开修改密码和退出，再点它收起。字段名仍是 `old_password` 和 `password`，按钮仍是「修改密码」和「退出」。

现在面板一旦展开，点正文、点导航或换到另一页，它都还开着。展开之后，下面任一情况都把它收起：

- 指针按在账号按钮和面板以外的地方
- 按下 Escape
- 地址换到另一教师页

按在面板内部的输入框、「修改密码」或「退出」上，不因为这一按而收起。修改密码失败时面板保持打开，失败句仍只在任务列表正文里显示，句子不变。修改密码成功后仍进入任务列表，面板是收起的。退出后仍是预选「教师」的登录页。

## 验收

前端没有测试运行器，这一规格不新增。已有的 Python 课堂测试不改。

在宽于 800px 的窗口里打开任务列表：导航窄于现在的 212px，任务行铺到导航右侧，不再在 840px 处停住。打开任务详情、新建任务、目标和班级详情，标题上方都有「返回」，并且进入上表那一页。班里有学生时，学生详情同样有「返回」，进入该班。四个一级页面没有「返回」。

在任务详情点开账号面板，再点题目区域，面板收起。再打开，按 Escape，面板收起。打开后面点「班级」，班级页上的面板是收起的。在面板里点「修改密码」时，这一按本身不把面板收起。
