# 模型决策智能体

高中信息科技课里，学生做任务时，决策智能体给出预设提问，并在学生求助后从六类支架中选一类。本规格只把决策智能体换成 DeepSeek。会话怎样接收决策智能体、求助失败时怎样留下已有支架和预设提问，仍按支架闭环规格执行。

支架智能体、任务生成方和目标提炼方不在这里。测试不访问网络。

## 组件

新增模型决策智能体。会话仍接收一个决策智能体。已有的脚本决策智能体和已有测试保持不动。

**模型决策智能体**实现现有的 `suggest(record)` 和 `choose_type(record, question)`。每个方法组两条消息，调用一次完成函数，解析正文并交回。它不保存记录，不读取密钥，也不调用支架智能体。

完成函数是任务生成里已有的 DeepSeek 完成函数。测试换上返回事先写好正文的函数。本规格不修改这个完成函数。

构造会话时，把模型决策智能体当作原来的决策智能体传入。会话本身不修改。

## 提示词

两条系统消息都是固定说明。用户消息只写这一份任务记录。

更新预设提问时，系统消息要求模型只回一个 JSON 对象，不要代码块，不要其他文字。顶层只有「预设提问」。它的值是字符串数组，数组可以是空的。每一条都不能为空白。空白不算已填写。不要写出学情。

选定类型时，系统消息要求模型只回一个 JSON 对象，不要代码块，不要其他文字。顶层只有「类型」。它的值是字符串，并且正好是反馈、提示、指导、解释、示范、提问之一。不要写出学情。

用户消息按题目顺序写。每题包含题型、题干、选项或作答要求、参考答案、解析、当前作答、修改痕迹。选择题的题型写成「单选」或「多选」，并列出全部选项。判断题的题型写成「判断」，选项是正确和错误。综合题的题型写成「综合」，并写上作答要求。开放题没有参考答案或解析时，那一项留空。选择题和判断题的当前作答按记录里的先后写出当前选择，综合题写当前文字。没有作答时这一项为空。修改痕迹按先后列出。没有修改痕迹时这一项为空。记录末尾写停留的秒数，以及历次求助的原话和来源。来源写成「预设提问」或「自己写的」。

选定类型时，同一份记录的末尾再写这次提问的原话。

用户消息用拼接组成，不对这段正文做字符串格式化。不放其他任务、知识库、教学目标或支架正文。

## 正文

正文去掉前后空白后，必须直接是一个 JSON 对象。完成函数交回的不是字符串时，也算解析失败。

更新预设提问时，顶层只有「预设提问」，值是数组，每一项都是字符串：

```json
{"预设提问": ["这道题在问什么？", "  能再看一看条件吗？"]}
```

去掉前后空白后还有字的条目，按模型原文保留，顺序不变。重复的也保留。只有空白的丢掉。

选定类型时，顶层只有「类型」，值正好是六个字之一：

```json
{"类型": "提示"}
```

## 失败

解析失败时，模型决策智能体抛出它自己的 `Rejected`。这个异常不属于任务发布。完成函数抛出的异常原样传出。模型决策智能体不接住这些异常。完成函数只调用一次，不重试。

下面这些是解析失败：

- 正文去掉前后空白后不能直接解析成约定的 JSON。包在代码块里也算失败。
- 顶层键多了或少了。
- 「预设提问」的值不是数组，或其中有不是字符串的值。
- 「类型」的值不是字符串，不是六类之一，或去掉前后空白后才等于其中一类。

下面这些不是调用失败。空白项被丢掉，其余按原来的先后交回。一条合格的都没有时，返回空元组：

- 某一条预设提问为空白。空白不算已填写。
- 「预设提问」是空数组。

会话不修改，因此现场按现有规则保留：

- 求助时，`Rejected` 或完成函数抛出的异常被会话接住。已有支架和预设提问保留。
- 改作答时，作答先写入，然后再取预设提问。这一步抛出异常时，异常传到调用方，预设提问仍是上一次的。
- 返回空元组时，会话把预设提问更新为空。
- 打开会话时，第一次取预设提问就失败，会话建不起来。

## 测试

已有的脚本决策智能体和已有测试保持通过。新增测试不访问网络。

- 更新预设提问时，系统消息只约束「预设提问」这份 JSON。用户消息含题型、题干、选项或作答要求、参考答案、解析、当前作答、修改痕迹、停留时间和历次求助。
- 选定类型时，系统消息只约束「类型」，并写明六类。用户消息在同一份记录末尾写上这次提问的原话。
- 一段含空白和有字条目的预设提问，只交回有字的条目。顺序与丢掉空白之后的顺序一致，原文保留，重复的也保留。完成函数只被调用一次。
- 空数组或全部为空白时，返回空元组。
- 代码块、键不对、数组里有非字符串、类型不在六类之中、类型带空白，或完成函数抛出异常时，预设提问方法或类型方法按上面的失败规则结束。完成函数只被调用一次。六类类型各自都能通过。
- 把模型决策智能体传进现有会话后，改作答得到的页面使用这次交回的预设提问。求助时类型非法，已有支架保留。

会话、支架智能体、任务生成、目标提炼和已有的 DeepSeek 完成函数不被修改。
