# 按文字生成

高中信息科技课里，教师在本机页面上提交一段文字。模型从这段文字里生成目标，并生成单选、多选、判断、综合题目。本规格只描述教师页上的这一处。

教材和课标的预置内容不在这里。知识库、已经保存的课时目标和学段目标、课时生成、学段生成、学生页和任务页的原有规则不改。测试不监听端口，不打开浏览器，也不访问网络。

## 服务

生成页并进现有教师页。路径是 `/generation`。课堂里这条地址带上 `/teacher`，单独调用教师页时不带前缀。末尾多一个斜杠不影响这个判断。查询字符串不参与判断。

任务生成记录增加按文字生成。教师页调用这一入口，一次提交最多调用一次。没有任务生成记录时不调用。这一入口不读取知识库，也不读取已经保存的课时目标或学段目标。课时生成和学段生成仍按原来的规则工作。

生成页不另记草稿。每次提交只带这次的文字。空白不算已填写。

目标页的查询表单旁有「生成」，指向生成页。一打开查询表单就有，包括还没查看的时候。点它只打开生成页，不提交目标页里已经填写的内容。教师列表不增加「生成」。`/` 仍是课堂入口，那里不增加「生成」。

按文字生成得到的目标只供这次核对，不写入目标库。核对通过后创建一份未发布任务，不写入课时来源或学段来源。这份任务出现在任务列表里。目标页只列出带有对应来源的任务，所以这份任务不出现在目标页的任务链接里。

正式运行时，按文字生成使用课堂里已有的补全。测试注入事先写好的交回。

## 页面和路径

用 GET 打开生成页时，只显示一个可以写下一段话的文字框，以及提交按钮「生成」。文字框的名字是 `text`。这时没有失败句，没有目标，也没有题目。

提交地址同样带上教师前缀。同一次提交里 `text` 取最后一项。没有 `text` 时，文字算空的。失败时仍停在生成页，状态是 200。文字框里留下这次提交的原文，并显示「生成失败，没有创建任务」。

生成成功时，这次响应就是现有的任务页，状态是 200。页面上是这份新任务的题目，并标为未发布。之后的修改、发布和删除都按任务页已有的规则。

原文、题目和标识都按文字写进页面。HTML 用拼接，不用 `str.format`。

学生页不增加这条路径。学生地址 `/student/generation` 仍显示「任务不存在」，状态是 404。教师页上不认识的地址仍是「任务不存在」。

## 交回

模型交回一份对象，有且只有这三个键：读法、目标、题目。

读法有两种合格写法。一种有且只有单选、多选、判断、综合。某一类的值是大于或等于 0 的整数，表示指定了这个数量。整数必须是数字，不能是字符串或小数。某一类的值是「未指定」，表示由模型决定。缺一类、多一类、出现这四种以外的题型，或某一类既不是这样的整数也不是「未指定」，都算数量说不清。另一种是去掉两端空白后还有内容的字符串。这表示教师没有写明题目类型和数量，四种都由模型决定，不算数量说不清，也不算失败。去掉两端空白后是空的，仍算数量说不清。

目标是数组，至少一条。每条有且只有维度和表述这两个必填值，都是字符串。多出的字段忽略。维度是信息意识、计算思维、数字化学习与创新、信息社会责任之一。表述去掉两端空白后还有内容。

题目有且只有单选、多选、判断、综合，每一类都是数组。题目先排成这个顺序，同一类保持交回的先后。字段和合格规则如下。空白不算已填写。

- **单选和多选。** 有且只有题目、选项、参考答案、解析。题目不能为空白。解析可以空着。选项至少两个，互不相同，且都不能为空白。选项和参考答案都是字符串数组。参考答案写成一个词时，按一项答案收下。单选的参考答案只有一项。多选的参考答案至少一项。参考答案的每一项都在选项里，且互不相同。写不成题目的那一项丢掉，其余题目仍留下。
- **判断。** 有且只有题目、参考答案、解析，三个值都是字符串。题目不能为空白。解析可以空着。参考答案是「正确」或「错误」。写不成题目的那一项丢掉，其余题目仍留下。
- **综合。** 有且只有题目、作答要求、参考答案、解析，四个值都是字符串。题目和作答要求都不能为空白。参考答案和解析可以空着。

指定了数量的那一类，题数必须和读法一致。指定为 0 的那一类就不能有题。未指定的那一类接受交回的题数，可以是 0。读法去掉两端空白后还有内容时，四类都按未指定处理，题数照交回保留。四类合起来至少一道。

## 失败

下面这些情况都显示「生成失败，没有创建任务」，状态是 200，文字框留下提交的原文，不创建任务。知识库、目标库和已有任务都保持原样。

- 文字去掉两端空白后为空。这时不调用模型。
- 教师页没有任务生成记录。这时不调用模型。
- 模型调用失败，或交回无法按上一节接受。这里包括读法缺类或数量说不清、出现四种以外的题型、目标为空或维度不合格或表述为空白、题目不符合上一节、指定数量对不上、指定为 0 的那一类仍有题、四类合起来没有题。教师没有写明题目类型和数量，且读法去掉两端空白后还有内容，不在此列。

## 测试

测试调用教师页和课堂的处理函数，注入事先写好的模型交回。测试不调用监听，不打开浏览器，也不访问网络。

下面这些必须成立：

- 目标页一打开查询表单就有指向生成页的「生成」。教师列表和课堂入口没有这条链接。课堂里链接以 `/teacher` 开头，单独调用教师页时不带前缀。
- 用 GET 打开生成页时，只有文字框和「生成」。没有失败句，没有目标，也没有题目。末尾多一个斜杠或带查询字符串，仍打开这一页。
- 提交一段写明单选数量、其余三类为「未指定」的文字后，创建一份未发布任务。响应是这份任务的任务页。题目按单选、多选、判断、综合排列。指定的单选题数一致，未指定的类照交回的题数保留。目标库里没有新目标。任务列表里有这份任务。它不带课时来源或学段来源，目标页的任务链接里没有它。
- 交回里读法去掉两端空白后还有内容，并带有合格题目时，核对照交回的题数保留。读法去掉两端空白后是空的，或四种题都是空数组时，仍然拒绝。
- 文字去掉两端空白后为空、没有任务生成记录、模型调用失败、读法缺类或数量说不清、出现四种以外的题型、目标为空或维度不合格或表述为空白、题目不符合规则、指定数量对不上、指定为 0 的那一类仍有题、四类合起来没有题，都显示「生成失败，没有创建任务」，状态是 200，文字框留下提交的原文，不创建任务。空白和没有生成记录时不调用模型。
- 失败时知识库、目标库和已有任务保持原样。课时生成和学段生成仍按原来的规则工作。
- 文字里的 `<` 按文字显示。学生地址 `/student/generation` 仍显示「任务不存在」，状态是 404。
