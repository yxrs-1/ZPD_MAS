# 学生页面

高中信息科技课里，学生在本机浏览器里打开已发布的任务，作答、求助、查看支架并提交。本规格只描述这个页面服务。

教师页面、教材和课标的预置内容不在这里。任务仍由现有库函数事先发布到这次服务使用的任务目录。闭环、发布、决策智能体和支架智能体的既有规则保持不变。测试不监听端口，不打开浏览器，也不访问网络。

## 服务

新增一个学生页面服务。它持有一份任务目录、一个决策智能体和一个支架智能体。成功建立的会话保留在这个进程里，直到进程结束。会话、任务目录、素材导出和已有的模型模块都保持原样。

这一服务只有一名本地学生，没有登录。页面有两处：待办，以及一份任务。处理函数返回待办页面、任务页面，或当前支架里某一件素材的文件名和内容。

正式运行时，两个智能体使用已有的 DeepSeek 决策智能体和支架智能体。测试把脚本智能体和任务目录交给处理函数。

服务和它使用的任务目录都只活在这次进程里。进程结束后，任务、作答和会话都不保留。目录是空的，待办就是空的。这次不预置样例任务。

## 待办

待办只读取目录里已发布的任务，并显示待办或已完成。每条只显示任务标识和这个执行状态。学生从这里进入任务。

任务出现在待办里时，服务不开始它，也不建立会话。待办不累计停留时间。待办里没有参考答案、解析和支架。

## 任务页

学生打开一份已发布的任务时，若还没开始，服务先开始它，再建立会话。建立会话时，决策智能体生成预设提问。这份会话保留到进程结束。之后的改答案、求助、提交和再次打开，都使用同一份会话。

任务页按题目顺序显示每一题：

- 选择题显示题干、单选或多选、选项和当前选择。
- 判断题显示题干、正确和错误、当前选择。
- 综合题显示题干、作答要求和当前文字。

提交之前，页面上没有参考答案和解析。题干、选项、作答要求、作答、预设提问、求助原话、支架文字和文件名都按文字写进页面。

预设提问列在页面上。学生点一条，或自己写一句，都是一次求助。求助成功后，页面显示这次支架的文字，并按件显示图片素材、思维导图、结构图和微格动画。每件显示类型和文件名，并用该件自己的地址显示内容。模型返回的 HTML 不整页嵌进页面。

页面同时列出历次求助的原话。某次没有产生新支架时，这一条下面没有支架，页面上仍显示上一次的支架。

## 作答、求助和停留时间

学生可以修改任何一题的作答。修改被接受后，预设提问按新的整份作答更新，已有支架留在页面上。不合格的作答被拒绝，页面仍显示原来的作答。

服务在画出任务页时记下时刻。学生下一次改答案、求助、提交或再次打开该页时，把经过的秒数加到已保存的停留时间上。经过的秒数不大于零时，不加。不论这次修改是否被接受，只要当时已有会话，停留时间都先累加。空白提问不调用两个智能体，停留时间仍会记下。

## 素材

学生可以按件把当前支架里的素材保存为文件，一次一件。服务返回该件的文件名和内容。同一文件名有多件时，返回当前支架里的第一件。其他文件名不返回内容。页面不把整份 HTML 保存为文件。

没有可导出的素材时，页面不提供导出。

## 提交

学生提交后，作答变为只读，求助入口关闭，预设提问清空。已有求助和支架仍可查看。页面显示提交当时的题目、作答、参考答案和解析。综合题没填的参考答案或解析就是空的。执行状态变为已完成。

## 失败

学生打不开未发布的任务，也打不开目录里没有的任务。页面不显示它的题目、作答、参考答案或解析。

打开任务时，若还没有会话，服务先保证任务已开始，再建立会话。建立会话失败时，不保存会话。页面显示这份任务的题目和已有作答，没有预设提问，也没有支架。学生再次打开时，服务重新建立会话。还没有会话时，改答案、求助和提交都先重新建立会话；仍然失败时，这些操作不发生，页面保持原样，停留时间也不记下。

改答案时，作答先保存，再更新预设提问。更新失败时，新的作答留下，预设提问仍是上一次的，已有支架不变。页面重新显示这份任务。

求助时，类型不在六类之中、调用失败，或支架没有文字也没有四类素材，页面不显示新支架。已有支架、预设提问和已有对话都保留。这次提问仍记在对话里，这一条下面没有支架。

提交之后再改作答或再求助，都会被拒绝。页面停在提交时的题目、作答、参考答案、解析和已有对话上。

## 测试

测试直接调用处理函数，并传入一份任务目录和脚本智能体。测试不监听端口，不打开浏览器，也不调用 DeepSeek。

- 目录是空的，待办就是空的。未发布的任务不在待办里。直接打开它时，页面不显示题目、作答、参考答案或解析。
- 已发布的任务在待办里显示待办。只出现在待办里时，任务还没开始，也没有会话。
- 学生打开这份任务后，任务开始，并建立一份会话。页面有题目、作答处和预设提问，没有参考答案、解析和支架。再次打开仍用这份会话。
- 修改作答被接受后，预设提问更新，已有支架还在。不合格的作答被拒绝，页面仍是原来的作答。
- 点一条预设提问，或自己写一句，都会把六类中的一类和这句原话交给支架智能体。页面显示支架文字，并按件显示四类素材。模型返回的 HTML 不整页出现。
- 学生可以按件保存素材，得到该件的文件名和内容。同一文件名有多件时，得到当前支架里的第一件。其他文件名没有内容。没有素材时，页面不提供导出。
- 空白提问不调用两个智能体。类型不在六类之中、调用失败或支架为空时，已有支架和预设提问都保留，这次提问记在对话里，这一条下面没有支架。
- 待办不累计停留时间。学生下一次改答案、求助、提交或再次打开任务页时，经过的秒数加到已保存的停留时间上。经过的秒数不大于零时，不加。
- 建立会话失败时，不保存会话。页面有题目和已有作答，没有预设提问和支架。再次打开会重新建立会话。会话仍然建立不了时，改答案、求助和提交都不发生。
- 作答已经保存、预设提问却更新失败时，新的作答留下，预设提问仍是上一次的。
- 提交后显示已完成。作答只读，求助入口关闭，预设提问清空，已有对话还在。页面显示提交当时的题目、作答、参考答案和解析。之后再改作答或再求助会被拒绝，页面停在这个结果上。
- 新建一份服务和一份新的任务目录时，另一份服务里的任务、作答和会话都不在。正式运行使用已有的 DeepSeek 决策智能体和支架智能体。测试用脚本智能体，不发出网络请求。

会话、任务目录、素材导出、决策智能体、支架智能体和已有的 DeepSeek 完成函数不被修改。
