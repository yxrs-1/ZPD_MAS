# 任务生成

高中信息科技课里，教师按已经保存的四维教学目标生成任务。本规格只描述一次生成如何读一份目标记录、检查题目，并创建未发布的任务。发布后的作答、求助和提交不在这里。

生成方是一个可替换的接口。测试使用事先写好的题目，不接真实模型。

知识库和目标库在这次生成里都不被修改。

## 记录

生成成功后有两样东西。

**未发布的任务**由现有的任务创建保存。题目按这个顺序排列：单选、多选、判断、综合。某一类的数量是 0，这一类就不出现。同一类里面，顺序与生成方交回的顺序一致。每道题仍用现有题型的字段，不另记某一条目标。

**教师查看的来源记录**按这份任务的标识另存，记下生成时用的那一份目标记录。课时记录记下版本、册次、课时。学段记录记下学段。两种只存一种。

这份来源记录只供教师按任务标识查看。学生页面、待办列表和两个支架智能体都读不到它。不是这次生成创建的任务，没有来源记录，查询结果为空。

之后修改或删除目标，任务和这份来源记录都保持生成时的样子。教师在发布前修改题目，仍按现有的任务发布规则，来源记录保留。发布之后，来源记录仍在。

## 一次生成

教师指定一份目标记录，并给出单选、多选、判断、综合四种数量。指定课时时用版本、册次、课时。只给学段时用学段。文字有一处不同，就是另一份记录。

没有这份目标记录，四种数量都是 0，或某个数量不是零或正整数时，不创建任务，也不调用生成方。

其余情况下才调用生成方。它只能读到四种数量，以及这份记录里每条目标的维度、表述和来源。

生成方可以按任何顺序交回题目。保存前先分成单选、多选、判断、综合，同一类保持它交回的先后。然后检查两件事：每一类的数量与教师指定的数量一致，每道题都符合任务发布规格里的题目规则。

- **选择题。** 题目、单选或多选、至少两个互不相同且非空的选项、参考答案、解析。题目和解析都不能为空白。单选的参考答案是其中一个选项。多选的参考答案至少包含一个选项，且每一项都在选项里。
- **判断题。** 题目、参考答案、解析。题目和解析都不能为空白。参考答案是「正确」或「错误」。
- **综合题。** 题目、作答要求，两者都不能为空白。参考答案和解析可以空着。

空白不算已填写。

两项都通过，才创建未发布任务，并按这个任务的标识保存来源记录。任务没有创建成功时，不保存来源记录。

有一项不通过，或生成方调用失败，整次拒绝。不创建任务，也不保存来源记录。已有任务保持不变。

## 测试

下面这些必须成立：

- 指定一份课时目标记录和四种数量后，创建一份未发布任务。题目顺序是单选、多选、判断、综合。数量为 0 的那一类不出现。同一类保持生成方交回的先后。教师可以按任务标识看到版本、册次、课时。
- 指定一份学段目标记录时，教师看到的是学段。这份记录与同一学段的课时目标记录互不影响。
- 版本、册次、课时或学段有一处不同，就是另一份记录。没有这份目标记录时，不创建任务，也不调用生成方。
- 四类数量都是 0，或某个数量不是零或正整数时，不创建任务，也不调用生成方。
- 某一类数量与指定的不一致、有题目不符合上述题型规则，或生成方调用失败时，整次拒绝。不创建任务，也不保存来源记录。已有任务保持不变。
- 学生页面、待办列表和两个支架智能体都读不到这份来源记录。不是这次生成创建的任务，没有来源记录。
- 生成之后，修改或删除目标，任务和来源记录保持生成时的样子。教师在发布前修改题目，仍按现有规则，来源记录保留。发布之后，来源记录仍在。
- 知识库和目标库不被修改。

发布后的作答、求助和提交不在这次测试里。
