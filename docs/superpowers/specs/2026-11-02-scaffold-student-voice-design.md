# 支架文字改为对学生说

学生提问后，支架智能体仍按已经选定的类型交回「文字」和「源码」。本规格只改文字的读者，以及文字写成教师口吻时的一次重写。六类支架的选择、源码格式、示例、本地渲染、微格动画和学生页都不改。

2026-10-19 的模型支架智能体规格仍有效。其中「完成函数只调用一次，不重试」只在本规格写明的口吻重写处放宽。解析失败、完成函数抛出的异常、空字符串，仍不重试。

## 读者

文字的读者是正在做这道题的学生。两三句，用「你」直接对这个人说，不引用题干原句，不写出参考答案。

有图时，第一句是「先看下面这张图。」后面的句子告诉他看图里的哪一层关系。没有图时，直接回答这次提问，仍用「你」。

文字里不出现这些字样：学生、教师、引导、让学生、请学生、学情。

因此「该问题可以先从 range 入手，引导学生用最小示例动手验证」要写成对学生说的话，例如：「可以。for 走到一个空序列时，循环体一次也不会执行。你用 `for x in []: print(x)` 跑一下，看打印出现几次。」

## 提示词

系统消息在现有 JSON 规则之后写成：

```
只回一份 JSON 对象，不要代码块，不要其他文字。
顶层只有「文字」和「源码」。两个值都是字符串，可以是空字符串。
不要写 HTML，不要写文件名。
文字写两三句，不要引用题干原句。
读者是正在做这道题的学生。用「你」直接对这个人说。
文字里不出现：学生、教师、引导、让学生、请学生、学情。
支架的文字和源码不要写出参考答案，也不要写出学情。
```

有图时，用户消息里原来的「文字的第一句让学生看这张图。」改成「文字的第一句是：先看下面这张图。」没有图时仍是「素材：无」和「源码留空。」用户消息的题目、作答、示例源码、支架类型和这次提问保持原样。

## 重写

检查只看解析成功之后的「文字」，按子串匹配上面六个字样。源码里出现这些字样不触发重写。空字符串和只有空白的文字不匹配，交回方式与现在相同。

第一次文字命中时，用原来的系统消息和用户消息再调用一次，并加上一条用户消息：

```
上一稿是在对教师说话，按规则改成直接对学生说的话。
上一稿：
```

这条追加消息的角色是用户。「上一稿：」后面接第一稿的文字原文。完成函数每返回一次字符串，就按现有方式记下这一次。第二次若在返回字符串之前抛出异常，只留下第一次的记录。第二次调用前，把流式进度里已经推出的文字清掉。完成函数仍边收边推。前端每次用整段替换正在显示的文字，第二稿会盖住第一稿。完成函数和前端不改。

第二次的文字无论是否仍命中，都放进草稿并交回，不再调用。追踪元数据「支架正文」记这份最终文字。

第一次正文解析失败时，抛出现有的 `Rejected`，不进行第二次调用。第一次完成函数抛出的异常原样传出，也不进行第二次调用。第二次解析失败或第二次完成函数抛出异常时，同样按现有规则传出；第一稿丢弃。会话不改，因此学生仍留下上一次的支架。

## 测试

测试不访问网络。`tests/test_model_scaffold_prompt.py` 改为锁定新的系统消息，以及「文字的第一句是：先看下面这张图。」

再补这些行为：

- 文字不含上述字样时，完成函数调用一次。
- 文字含「引导学生」时，完成函数调用两次。第二次的消息是第一次的两条再加上面的用户消息，草稿文字是第二次的原文。
- 第二次文字仍含「学生」时，仍交回第二次的文字，调用停在两次。
- 源码含「学生」、文字不含上述字样时，调用一次。
- 第一次是代码块、键不对，或完成函数抛出异常时，调用一次，异常按现有规则传出。
- 第一次命中、第二次解析失败或完成函数抛出异常时，调用两次，异常传出。

决策智能体的提示词、渲染器、会话和学生页的测试保持通过。
