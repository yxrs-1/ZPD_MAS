# 学生仪表盘

学生登录后的页面改用教师仪表盘同一套纸面：左侧导航、右侧正文、粉笔黄当前项、楷体标题。现有的待办、作答、提问、支架和提交都留在这一页里，并接到已经存在的学生接口。登录页不改。教师页的导航、返回和账号面板不改。

不新增任务标题。列表和任务页仍用任务标识。不把模型返回的 HTML 整页嵌进页面。学生不能在这里改密码。

## 外壳

学生页使用教师页已有的 `desk`、`rail`、`stage`、`sheet`。颜色、字重、标志和 800px 以下导航改到正文上方的规则都沿用，不另做一套。

导航只有一项，文字是「待办」，指向 `/student`。待办和任务详情都标在这一项。底部是学生姓名。点它展开面板，面板里只有「退出」。再点姓名、点面板以外、按 Escape，或换到另一页，面板收起。点「退出」清除名为 `student` 的 Cookie，回到登录页。面板不提供修改密码。

## 待办

`/student` 读取 `GET /api/student/tasks`。每一行是任务标识和状态。状态仍是接口给出的「待办」或「已完成」，用教师页已有的标记样式。点一行进入 `/student/tasks/{task_id}`，链接写在 `href` 上。

数据还没回来时不显示「还没有任务」。回来之后一个任务都没有，写「还没有任务。教师布置之后会出现在这里。」

## 任务

任务详情读取 `GET /api/student/tasks/{task_id}`。打不开时回到待办。标题上方有「返回」，指向 `/student`，不使用浏览器后退。

每一题显示题型和题干。题干换行，不截成一行。有作答要求就显示。单选和判断用单选，多选用多选。选中的一项左边是粉笔黄。综合题用现有的多行输入框。未提交时可以改，并可以「保存作答」。保存调用 `POST /api/student/tasks/{task_id}/answers`，字段仍是综合题的 `text` 和其他题的 `selected`。

`locked` 为真时，作答不能改，不显示「保存作答」。这时题目下方显示「参考答案」和「解析」，句子用接口里的 `reference` 和 `explanation`。

`send_closed` 为假时，页面有预设提问、自己的提问和「提交」。点一条预设提问，调用 `POST /api/student/tasks/{task_id}/ask`，`source` 是「预设提问」。自己写的提问 `source` 是「自己写的」。去掉两端空白后是空的，不调用接口，输入留着。提交调用 `POST /api/student/tasks/{task_id}/submit`。提交前先确认「提交之后不能再改，也不能再提问。」取消则停留在这一页。

`send_closed` 为真时，不显示预设提问、提问框和「提交」。已经回来的支架和对话仍留在页面上。

## 支架

当前支架显示 `scaffold.text`。对话按接口顺序显示每一轮的问题和该轮支架文字。

支架和每一轮对话里的素材已经有 `kind` 和 `filename`，现在没有给学生仪表盘用的文件地址。增加两个只读接口，登录规则与打开任务相同。文件不存在时状态是 404，正文为空。找到时返回学生页里已有的那一份字节，并带上文件名。

- `GET /api/student/tasks/{task_id}/assets/{filename}` 读取当前支架的这一件
- `GET /api/student/tasks/{task_id}/turns/{index}/assets/{filename}` 读取这一轮支架的这一件

文件名以 png、jpg、jpeg、gif、webp、svg 结尾的，用图片显示，替代文字是文件名。其他文件显示类型和文件名，并提供「保存」，不把 HTML 嵌进页面。

## 动画

只加这三处，时长大约 0.2 秒，只用透明度和位移：

- 进入待办或任务时，正文沿用现有的 `sheet-in`
- 新出现的支架从下方 8px 淡入
- 保存、提问、提交进行中，按钮文字分别变成「正在保存」「正在提问」「正在提交」，并停用，直到接口回来

系统要求减少动画时，这三处都不动。导航、选中和面板不另加动画。

## 验收

前端不新增测试运行器。新的两个素材接口各补一条 Python 测试：已登录学生能取回当前支架和某一轮里的文件，未登录是 401，文件名对不上是 404。

在浏览器里用学生账号打开待办：外壳与教师页同一套纸面和粉笔黄，没有蓝灰卡片。点进任务能返回待办。未提交时可以改答案、保存、点预设提问、自己提问和提交。提交确认之后作答锁定，并看到参考答案和解析。支架文字出现时有一次淡入。有图片素材时图片来自上面的接口。减少动画时，进入页面和支架都不再移动。
