# 模型提炼目标

高中信息科技课里，教师按一次知识库检索提炼四维教学目标。本规格只把提炼方换成 DeepSeek。已有记录、空检索、不合格目标的丢弃、标识分配和保存仍按四维教学目标规格执行。

任务生成方、决策智能体和支架智能体不在这里。测试不访问网络。

## 组件

新增模型提炼方。`ObjectiveCatalog` 仍接收一个提炼方。已有的脚本提炼方和已有测试保持不动。

**模型提炼方**实现现有的 `extract(retrieval)`。它组两条消息，调用完成函数，把正文解析成目标草稿并交回。它不保存目标，不分配标识，也不改知识库。它不读取密钥。

完成函数是任务生成里已有的 DeepSeek 完成函数。测试换上返回事先写好正文的函数。本规格不修改这个完成函数。

一次提炼仍走 `extract_lesson` 或 `extract_stage`。已经有这份记录时，现有检查拒绝，不调用完成函数。这时即使检索没有资料，也仍然是拒绝。还没有记录，并且检索没有交回资料时，结果为空，不调用完成函数，也不保存。

## 提示词

系统消息是固定说明。用户消息是这次检索的原文和来源。

指定课时时，用户消息写上课时原文、教材来源、课标全文和课标来源。教材来源是版本、册次、课时、学段、页码。课标来源是名称、学段、条款号，并标明它是现行课标。只给学段时，用户消息只有课标全文和课标来源，不写教材。

固定说明要求模型只回一份 JSON 对象。维度只能是信息意识、计算思维、数字化学习与创新、信息社会责任。指定课时时，来源写成「教材」或「课标」。只给学段时，说明里写明来源只能写成「课标」。表述不能为空白。空白不算已填写。

## 正文

正文去掉前后空白后，必须直接是一个 JSON 对象。顶层只有「目标」这一个键。每条目标的键正好是维度、表述、来源，三个值都是字符串。完成函数交回的不是字符串时，也算解析失败。

```json
{
  "目标": [
    {"维度": "信息意识", "表述": "能识别信息", "来源": "教材"},
    {"维度": "信息社会责任", "表述": "遵守规范", "来源": "课标"}
  ]
}
```

数组可以是空的。「教材」对上这次检索的教材来源，「课标」对上这次检索的课标来源。草稿里的来源就是这次检索交回的那个来源对象。数组里的先后，就是交回现有筛选的先后。

形状通过之后，才交给现有筛选。维度不在四维之中、表述为空白、来源写成了「教材」和「课标」以外的字，或这次检索没有这种来源时，这条被丢掉，其余按原来的先后保留。

## 失败

解析失败时，模型提炼方抛出目标库的 `Rejected`。完成函数抛出的异常原样传出。目标库不接住这些异常。不保存记录，已有记录保持不变。完成函数只调用一次，不重试。

下面这些是解析失败：

- 正文去掉前后空白后不能直接解析成上面的 JSON。包在代码块里也算失败。
- 顶层键多了或少了，目标的键多了或少了，或值不是字符串。

下面这些不是调用失败。完成函数已经被调用过一次。不合格的条目被丢掉，合格的按原来的先后保存。一条合格的都没有时，不保存记录，结果为空，这次不分配标识。之后可以再提炼：

- 维度不在四维之中。
- 表述为空白。空白不算已填写。
- 来源不是「教材」或「课标」，或者这次检索没有这种来源。
- 「目标」是空数组。

## 测试

已有的脚本提炼方和已有测试保持通过。新增测试不访问网络。

- 指定课时时，系统消息写明 JSON 的形状、四个维度，以及来源可以是「教材」或「课标」。用户消息写上课时原文、教材来源、课标全文和课标来源。
- 只给学段时，系统消息写明来源只能是「课标」。用户消息只有课标全文和课标来源，没有教材原文。
- 一段含合格与不合格条目的正文交回后，只保存合格目标。顺序与丢掉不合格项之后的顺序一致。来源是这次检索交回的来源对象。标识按现有规则分配。完成函数只被调用一次。课时记录和学段记录都要测到。
- 空数组、全部不合格、代码块、键不对，或完成函数抛出异常时，不保存记录，这次不分配标识。已有记录保持不变。
- 已经有记录时，完成函数不被调用，已有目标保持不变。这时即使检索没有资料，也仍然是拒绝。还没有记录且检索没有资料时，完成函数不被调用，结果为空。
- 知识库不被修改。

目标库、知识库和已有的 DeepSeek 完成函数不被修改。任务生成、发布和作答不在这次测试里。
